# Contributing

External contributors must accept the [Contributor License Agreement](CLA.md)
before their pull request can be merged. Check the CLA box in the pull request
description from the account you used to submit the contribution. For joint
contributions, each contributor must affirm acceptance in a pull request comment.
Maintainers verify acceptance before merging.

Describe what changed and how you verified it. See the project README for build
and test instructions.
